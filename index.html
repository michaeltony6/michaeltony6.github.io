Computer architecture

Custom RISC CPU & Pipelined Processor

My own RISC-style instruction set with the full toolchain around it. A C simulator runs fetch-decode-execute with a two-pass assembler, a disassembler, tracing, profiling and runtime fault detection. Two Verilog cores implement the same ISA: a single-cycle core and a five-stage pipeline with forwarding, load-use stalls, branch flushes and CPI reporting.

Every program is checked against the C simulator as a golden model, and a browser debugger shows registers, memory and the pipeline cycle by cycle.

  • ISA24 instructions, fixed width
  • StateR0–R7, 256-word memory
  • CoresSingle-cycle + 5-stage pipeline
  • VerificationC vs. Verilog golden-model tests

Robotics · Simulation & control

Rutgers Dynamics

A modular humanoid simulation and control stack built on MuJoCo, MuJoCo-Warp and Isaac Lab, with articulated-body dynamics, actuator models, reinforcement-learning environments and GPU-parallel simulation.

On the hardware side, a 3-DOF robotic leg: analytical forward and inverse kinematics, joint-space PD control with real-time feedback, and Jacobian-transpose mapping from task-space forces to joint torques (τ = JᵀF). The sim-to-deployment layer handles position, velocity and torque control, torque saturation and asynchronous stepping.

Web tool · Image processing

Desmos Trace

Turns any image into a full-color, editable Desmos polygon list, entirely in the browser. No source image is embedded in the graph.

Adaptive mode splits the image into rectangles and merges a block only when every RGB channel stays within tolerance of the block’s rounded mean. Exact mode run-length encodes pixels so nothing is lost, and a compare view measures RMSE and maximum error against the decoded image.

  • ModesHigh fidelity, balanced, pixel exact, custom

  • Designed a RowHammer detector inspired by branch predictors in C++, using tagged history tables and saturating counters. It caught 100% of evaluated attacks with zero false negatives and a 0.3% false-positive rate.
  • Evaluated it across 60 workloads and 18 billion memory requests: detection latency down 42%, metadata down 68%, and benign workloads slowed by only 0.8%.
